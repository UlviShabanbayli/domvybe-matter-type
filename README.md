# Matter Type

**[Live demo](https://domvybe.com/projects/matter-type/)** · [Download the ZIP](https://github.com/UlviShabanbayli/domvybe-matter-type/releases/latest/download/matter-type-source.zip)

Open index.html in a modern browser. Edit the word, choose a color, disperse or assemble, and export a PNG. Keyboard: focus the canvas and press Enter or Space. Motion can be paused. No music is included. Google Fonts is optional; system fonts work offline.
